# Resume-Safe Claim Boundaries

## Allowed

- Built a fixed-role multi-agent planning runtime with strict Task Brief contracts.
- Implemented structured review findings, targeted bounded revision, and human-review escalation.
- Centralized multi-agent provider calls with attempt, retry, concurrency, and honest token accounting.
- Exposed repository tools over MCP through the existing ToolExecutor security boundary.
- Built deterministic mock contract benchmarks and authored evaluation harness/datasets with explicit limits.

## Must Qualify

- Say mock-validated, not live-validated.
- Say MCP schema publication uses Tool-owned schemas; do not claim runtime limits cannot drift.
- Say evaluation harness/dataset authored; do not claim a fair or completed comparison.

## Forbidden

Production-ready, high availability, distributed budget, true resume, live validated,
HTTP API authentication/authorization, six-agent quality improvement, human-reviewed
evaluation, or release-ready.
